Conectar con Last.fm

Last.fm registra lo que escuchas en Spotify. No necesitas Premium.

  1. Crea tu cuenta en last.fm y en Ajustes → Aplicaciones conecta Spotify.
  2. Crea una API key gratis en last.fm/api/account/create. El nombre y la descripción pueden ser cualquiera.
  3. Pega aquí tu usuario y la API key.
